# Site Hive — Lucas Cintra Veloso

- `site/index.html` — página para clientes de energia (economia na conta de luz)
- `site/oportunidade.html` — página para quem quer ser Licenciado

- `site/estilo.css` — cores e visual
- `HIVE-BASE-DE-CONHECIMENTO.md` — tudo sobre a Hive: plano, descontos, objeções

## Como editar pelo celular
1. Abra o repositório no app do GitHub ou em github.com.
2. Entre no arquivo, toque no lápis ✏️, altere o texto e toque em **Commit changes**.
3. Em 1 a 2 minutos o site atualiza sozinho.
